## About

A personal portfolio website for Muneeb Rehman, built as an interactive 3D experience. No framework, no build step — just open it and it runs.

## Features

- Interactive 3D scenes with Three.js
- 3D character and animation models
- Hover audio effects
- Smooth TweenLite animations
- Responsive layout

## Tech Stack

- HTML
- CSS
- JavaScript
- Three.js (r112)
- TweenLite

## Run Locally

No build step needed. Clone the repo and open `index.html` in a browser, or serve the folder with any static server:

```bash
git clone https://github.com/muneebrahmancmd/muneeb-rehman-portfolio-lusion.git
cd muneeb-rehman-portfolio-lusion
```

Then open `index.html`.
